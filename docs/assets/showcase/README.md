# Hopus showcase media

These images are new captures of the Hopus macOS windows. They were rendered from the app itself in an isolated session, using generated fixtures. No personal files, account details, or screen contents are included.

- `hopus-octopus-home.png`: Home with no file selected, light theme.
- `hopus-octopus-home-dark.png`: the same Home window in the dark theme.
- `hopus-wheel.png`: the tools wheel for two generated PDFs.
- `hopus-crop.png`: the image crop editor with a generated fixture.
- `hopus-trim.png`: the trim range control, with the selected span from 2.000 to 8.000 seconds.
- `hopus-window-wheel.png`: the window arrangement wheel in Turkish.
- `hopus-octopus-demo.gif` and `hopus-octopus-demo.mp4`: a 9-second silent walkthrough of those windows. `hopus-octopus-poster.jpg` is the opening frame. `demo-en.vtt` and `demo-tr.vtt` are the captions.

The MP4 is H.264, 960×640, and does not start playing on its own. Playback controls and captions are on the tutorial pages.
